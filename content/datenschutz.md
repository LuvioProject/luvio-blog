## 3. Kommentarsystem (Giscus)

Für Kommentare nutzt diese Website **Giscus**, ein Open-Source-Kommentarsystem, das auf GitHub Discussions basiert.

**Funktionsweise:**  
- Wenn du einen Kommentar schreibst, wirst du über GitHub OAuth authentifiziert
- Dein GitHub-Benutzername und dein Kommentar werden in einer GitHub Discussion gespeichert
- Es werden **keine personenbezogenen Daten** an Dritte weitergegeben
- Die Datenverarbeitung erfolgt durch GitHub (siehe GitHub-Datenschutzerklärung)

**Rechtsgrundlage:** Art. 6 Abs. 1 lit. f DSGVO (berechtigtes Interesse an einer Kommentarfunktion).

**Keine Verpflichtung:** Du musst keinen Kommentar hinterlassen. Du kannst alle Inhalte auch ohne GitHub-Account lesen.
